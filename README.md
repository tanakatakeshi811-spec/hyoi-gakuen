# 憑愛学園 -Possessed Heart-

小さな悪魔「テネブラ」に憑依された主人公が、普通の学園生活を送りながら
想い人との距離を縮め、時には邪魔者を陰で遠ざけていく――完全オリジナルの
3D学園シミュレーションゲームです。

- 3D校舎を自由に歩き回れる(three.js製、ビルド不要)
- 好感度・憑依度・疑いの目・信頼度の4メーターを管理しながら、Day制の
  時間割(授業・昼休み・放課後)をこなす
- 話す・贈り物を渡す・一緒に過ごす・告白するなどの恋愛ルートと、
  噂を流す・脅す・気絶させて拘束するなどの排除ルートの両方がある
- 結末は行動次第で変わる、全9種類のエンディング(両想い2種・BAD4種・
  卒業3種)

## 遊び方

`index.html` をブラウザで開くだけで遊べます(three.jsをCDNから読み込む
ため、インターネット接続が必要です)。

- 移動: WASD / 矢印キー
- 視点回転: マウスドラッグ
- 調べる・話す: E
- しゃがむ(隠密): Q
- ダッシュ: Shift
- スマホは画面下の仮想スティックに対応

## このリポジトリについて

- 単体3ページ構成(`index.html` + `style.css` + `data.js` + `person.js` +
  `game.js`)で完結。ビルド不要、three.js r128をCDN経由で読み込みます
- GitHub Pagesで公開しています

## 著作権・オリジナリティについて

いわゆる「学園シミュレーションゲーム」というジャンル・仕組み(好感度や
疑いの目などのメーター、排除ルートの存在など)のみを参考にしており、
実在するどの作品の固有名詞・キャラクター・世界観・素材も一切使用して
いません。キャラクター名・学校名・ストーリー・「小さな悪魔が憑依して
いる」という設定はすべてオリジナルです。
